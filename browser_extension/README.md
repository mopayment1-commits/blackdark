# BLACKDARK Browser Extension (H1 / E5)

Chrome/Edge MV3 overlay: **OQS + one Act/Wait sentence** on Binance, TradingView, Bybit, OKX, Coinbase — plus a popup Oracle.

## Install (unpacked — 1 minute)

1. Open Chrome → `chrome://extensions`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this folder: `browser_extension/`
5. Open Binance/TradingView — the BLACKDARK panel appears top-right
6. Or click the extension icon → type `BTC` → **Ask**

Default API: `https://blackdark-production.up.railway.app`  
Change in extension **Settings** if you use localhost (`http://localhost:8080`).

## What it shows

- Decision action: Act / Wait
- One English sentence
- Opportunity score + prediction id (when available)
- Anti-Hype footer

## Not included

- Publishing to Chrome Web Store (needs your developer account)
- Auto-trade / injecting orders
