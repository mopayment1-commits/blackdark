## 2) العمارة (نقطة نقطة)

المعمارية **مونوليث FastAPI** (`dashboard.py` + `api/routers/*`) وليست شبكة خدمات مدفوعة. هذا اختيار صريح لسقف عدم الدفع، لا ادّعاء Kubernetes/multi-AZ.

```
نيّة المستخدم (لوحة / عدسات)
        ↓
أبطال القرار (Oracle · دفتر الدقة · شهادات)
        ↓
طبقة بيانات قانونية (تطبيع · مصدر · طزاجة)
        ↓
حقيقة البث LIVE|STALE|DEGRADED|UNKNOWN + كتب L2
        ↓
أوركل / أربتراج / مخاطر
        ↓
حقيقة التنفيذ (إشاري ≠ قابل للتنفيذ) → OMS ورقي → منصات
        ↓
شهادة قرار + سلسلة تدقيق + تنبيهات داخل التطبيق
```

| الطبقة | الملفات الملزمة | الحكم |
|---|---|---|
| مدخل HTTP | `dashboard.py`، `api/routers/*.py`، GraphQL `/graphql` | يعمل محليًا؛ OpenAPI العام يُصفّي أسطح الكتابة الحساسة |
| هوية | `auth_service.py`، `identity_service.py`، `oauth_service.py` | جلسة+PBKDF2+TOTP تعمل؛ OAuth حي `ops_config` |
| قرار | `ai_oracle.py`، `decision_e2e.py`، `decision_certificate.py` | مسار ورقي/إثبات يعمل؛ التقييم الذاتي لنفس التيك ممنوع |
| سوق | `aggregator.py`، `full_catalog_mesh_proof.py`، `native_regional_cex_fetcher.py` | سعر الكتالوج 100%؛ L2 مؤسسي 95/100؛ المتبقي `synthetic_mid` |
| تنفيذ | `oms.py` ≠ `execution_engine.py` | ورقي/تجريبي كامل؛ `live_fill` حاجز جغرافي 451 |
| أسرار | Fernet + ملفات 0600 | ليست HashiCorp Vault إنتاجًا؛ profile `vault-dev` اختياري محلي |
| بيانات | SQLite في الإطلاق الناعم؛ Postgres مطلوب للإنتاج الصارم | HA Postgres محلي **VERIFIED_COMPLETE** الوحيد؛ ≠ cloud multi-AZ |
| صدق | `product_capability_inventory.py`، `public_readiness.py`، `prove_four_blockers.py` | ثلاث طبقات أدلة منفصلة |

مخاطر معمارية (صادقة، ليست أعطالًا مخفية):
- `dashboard.py` ملف ضخم — سطح صيانة لا سطح زائر.
- تكرار Operation ID في OpenAPI (تحذير FastAPI) — لا يكسر الصفحات.
- اعتماد TestClient على عمر التطبيق كامل — ثقيل لكن هو إثبات HTTP الملزم.
