# BLACKDARK — دستور المنتج الملزم (Product Constitution)

> **الحالة:** ملف مرجعي **ملزم واجب التنفيذ** — أصل مميزات المشروع  
> **الصلاحية:** أعلى من قوائم الأفكار / brainstorm / ملفات الميزات المرفوعة  
> **القاعدة:** أي ميزة جديدة تُرفض ما لم تُصنَّف تحت إحدى الطبقات أدناه أو تحت إحدى القدرات الثماني  
> **آخر اعتماد:** 2026-08-05

---

## 0) جملة الشمال (North Star)

> لا نبيع 500 مؤشر. نبيع **قرارات سوقية موثّقة**، بـ **Truth Score قابل للتنفيذ**، و**عمر فرصة متوقع**، و**معجم إشارات مُسمّى**، وحزمة إثبات جاهزة للصناديق ولجان الاستحواذ.

**مبدأ المنافسة:** التفرد والانبهار والحلول الجادة — لا ميزانية مقابل العملاقة.

---

## 1) المهم — لا يُمس (Core Canon)

هذه الطبقة أصل المنتج. حذفها أو إضعافها أو استبدالها بـ «مؤشرات تجميلية» = خرق للدستور.

### 1.1 عقل القرار
| القدرة | الالتزام |
|--------|----------|
| Oracle بجملة واحدة | قرار واضح واحد للمستخدم |
| Opportunity Score | درجة 0–100 قابلة للترتيب/API |
| تفسير AI | أسباب + مخاطر مع كل قرار |
| تعدد أطر زمنية | تقارب زمني قبل الثقة |
| ذاكرة مؤسسية + تعلم مستمر | Flywheel: predict → label → train → deploy |

### 1.2 مراجحة قابلة للتنفيذ
| القدرة | الالتزام |
|--------|----------|
| صافي الربح بعد الرسوم / السحب / الانزلاق | لا عرض لربح إجمالي وهمي |
| السيولة / قابلية الملء | عمق حقيقي قبل الإشارة |
| عمر الفرصة | زمن البقاء جزء من المنتج |
| Risk قبل التنفيذ | بوابة مخاطر + إمكانية إيقاف فوري |

### 1.3 إثبات الجودة
| القدرة | الالتزام |
|--------|----------|
| سجل دقة عام + hash chain | كل قرار قابل للتحقق علناً |
| Audit Trail | مسار تدقيق للمشتري/اللجنة |
| Drift | فشل مغلق عند انحراف النموذج |
| Data Flywheel | عينات حية مُسمّاة = Data Moat |
| Acquisition Pack | حزمة استحواذ جاهزة |

### 1.4 إشارات مختارة (لا تضخيم)
| الحزمة | الالتزام |
|--------|----------|
| Order Book / OBI / CVD | microstructure حقيقي |
| Whale / Funding / OI | إشارات مؤسسية |
| Sentiment / Macro | سياق نظامي |
| On-chain flow | تدفق من/إلى المنصات |

> أي إشارة خارج هذه الحزم تحتاج تعريفاً في Signal Registry + وزن + أداء — وإلا تُقتل.

### 1.5 توزيع
| القدرة | الالتزام |
|--------|----------|
| Free / Pro / Whale | شرائح واضحة |
| تنبيهات | قناة نمو (Telegram أولاً) |
| B2B API | مسار ARR مؤسسي |
| وضع مبتدئ / محترف | Progressive disclosure |

## 2) المميزات الفريدة — واجبة في النموذج (Differentiators Canon)

| ID | الميزة | تعريف ملزم | مشكلة من تحلها |
|----|--------|------------|----------------|
| **D1** | Proof-Native Oracle | كل قرار مربوط بدقة تاريخية عامة قابلة للتحقق (`prediction_id` + hash + نتيجة) | ثقة المستخدم + لجنة الاستحواذ |
| **D2** | Contradiction Veto | رفض تلقائي عند تعارض المصادر قبل عرض الفرصة | منع Buy الكاذب |
| **D3** | Net-Edge Truth | لا فرصة إلا بعد صافي ربح حقيقي قابل للتنفيذ (رسوم+سحب+انزلاق+زمن+ازدحام) | المحترف / جودة الإشارة |
| **D4** | Opportunity Half-Life | عمر الفرصة بالثواني + احتمال الاختفاء — منتج بحد ذاته | الحوت (وقت = مال) |
| **D5** | Regime-Conditional Models | نماذج/أوزان حسب نظام السوق (Risk-On/Off/Panic) لا نموذج واحد أعمى | نضج كمي للصناديق |
| **D6** | Evidence Pack API | حزمة جاهزة للصناديق ولجان الاستحواذ بزر واحد | غرفة بيانات المشتري |
| **D7** | Arabic-first Institutional UX | شرح مؤسسي عربي فصيح + وضوح للمبتدئ مع بيانات عالمية | انفجار MENA / المستخدم العادي |
| **D8** | Signal Registry | كل إشارة: تعريف / مصدر / وزن / أداء — وإلا تُقتل | Data Moat سيادي |

### خريطة الألم → الحل (ملزمة في الرسالة التسويقية والمنتج)

| الشريحة | الألم | الحل الفريد الملزم |
|---------|------|---------------------|
| عادي | غرق مؤشرات بلا قرار | Persona Clarity / Arabic-first — جملة: افعل / انتظر |
| محترف | إشارات لامعة غير قابلة للتنفيذ | Net-Edge Truth Score |
| حوت | الفرصة تموت أثناء التحجيم | Opportunity Half-Life |
| صندوق | لا رفض مسبب قابل للتدقيق | Truth + Contradiction Veto + Signal Registry |
| لجنة استحواذ | داشبورد ≠ أصل بيانات | Evidence Pack + Proof Chain |

## 3) القدرات الثماني — ضغط المنتج (Eight Capabilities)

كل بند في المشروع، والـroadmap، والـPRs، يُصنَّف تحت **واحدة فقط** من هذه القدرات — أو يُحذف:

1. **Unified Financial Oracle** — عقل القرار الموحد  
2. **Executable Arbitrage Engine** — مراجحة صافي ربح قابلة للتنفيذ  
3. **Net-Edge & Risk Gate** — Truth + Risk قبل العرض/التنفيذ  
4. **Public Accuracy & Audit Chain** — إثبات علني + سلسلة تدقيق  
5. **Labeled Data Flywheel** — تعلم مستمر على عينات حية مُسمّاة  
6. **Whale / Microstructure / Macro Fusion** — اندماج إشارات مختارة  
7. **Alert + Tiered Product** — تنبيهات + Free/Pro/Whale + مبتدئ/محترف  
8. **B2B Evidence & API** — Evidence Pack + واجهات مؤسسية

## 4) قواعد التنفيذ الملزمة (Governance)

1. **لا Feature Theater:** ممنوع إضافة مؤشر/رادار/خريطة بلا KPI + مصدر بيانات + مكان في Signal Registry.  
2. **محرك قرار واحد:** `unified_multimodal_v1` — ممنوع محرك قرار موازٍ.  
3. **Fail-closed:** تعارض حاد / Truth reject / Drift / OOD → WAIT أو Do Not Touch.  
4. **لا وعود ممنوعة:** لا HFT دون ملي ثانية، لا ضمان ربح، لا MEV theater تسويقي.  
5. **أولوية الشحن:** Core Canon (§1) ثم Differentiators (§2) ثم مضاعفات النمو — ليس العكس.  
6. **اختبار القبول:** أي PR يمس المنتج يثبت إلى أي قدرة من الثماني ينتمي، وأي D1–D8 يعزّز.  
7. **تعارض الوثائق:** عند التعارض، **هذا الملف يعلو** على قوائم الميزات المرفوعة وملفات brainstorm.
