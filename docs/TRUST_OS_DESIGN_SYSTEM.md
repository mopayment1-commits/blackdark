# BLACKDARK — Trust OS Design System v1 (binding)

**Calm Surface — Infinite Depth.** Decision Intelligence OS — not a data dashboard.

## Canon

- 1 product · 4 lenses · 6 heroes · Trust Pulse first-open
- Pricing: Proof Pass $0 · Decision Pro $29 · Whale Desk $199 · Institutional Talk-to-us
- Share = Proof Cards · Verify = Public Accuracy Ledger
- Anti-Hype: prove it, don’t manipulate

## Rejected (do not ship)

| Reject | Why |
|--------|-----|
| Inter / Roboto / Arial as brand type | Generic; fails brand test |
| Purple elevated (`#1A1A2E`) / purple–pink gradients | AI-default cluster |
| Soft Gold `#FFD700` as system accent | Crypto-bro / cheap signal |
| ARENA / prediction leaderboards | Outside Trust OS canon |
| FOMO seat counters / fake scarcity | Conflicts with Anti-Hype |
| Explorer / Plus $19 / Pro $49 ladder | Superseded by Trust OS pricing |
| First-viewport stats strips | Breaks hero budget |

## Motion (exactly three product motions)

1. **pulseIn** — Trust Pulse / section enter (300ms ease-out)
2. **flipFlash** — decision flip moment
3. **sharePop** — Share Proof feedback

No continuous aura spam. No breathing background entrainment.

## First viewport budget

Only: **Brand · one headline · one supporting line · one CTA group · Trust Pulse (or dominant proof visual).**  
No stats, schedules, Telegram blocks, or secondary marketing in the first composition.
